# 年末調整PDF自動転記アプリ（試作版）

国税庁/e-TaxのXMLから項目を読み込み、空欄PDFの座標に配置し、入力済みPDFを作成する試作アプリです。

## 利用方法
GitHub Pagesを有効にし、アプリをSafari等で開きます。XMLと空欄PDFを選択し、XML項目を選んでPDFの入力欄をタップします。最後に記入済みPDFを保存します。

## 現時点の制限
- e-TaxのXMLの正式な項目対応表は未実装です。XMLの末端要素を列挙する試作段階です。
- ZIP、.dataおよび住宅ローン控除の自動計算は未対応です。
- 日本語の配置は画像化方式の試作です。PDFへの配置位置は必ず目視で検証してください。
- iPhoneでの実機テストは未実施です。
- 読み込んだ個人情報はGitHubにはアップロードされません。ただしPDFライブラリはCDNから取得するため、厳密なオフライン構成は今後の課題です。
- マイナンバーは自動転記対象に含めない設計ですが、入力値や出力PDFは必ず確認してください。
- **税務署・勤務先へ提出する前に、元の申告書と照合してください。**

## 個人情報
実際のXML・申告書・マイナンバーなどはリポジトリへコミットしないでください。コードが公開されてもデータは公開されません。ただしブラウザ拡張・端末自体の安全性にも注意してください。

## 今後
国税庁公式XMLスキーマに対応した年度別マッピング、ZIP読込、住宅ローン控除（令和7年以降）、年調PDFごとのプリセット座標を実装予定です。

## v0.6: 公式XML項目に基づく基本情報の初期自動配置

- 令和9年分扶養控除（NTAAPP001）、令和8年分保険料控除（NTAAPP003）、令和8年分基礎・配偶者等控除（NTAAPP006）について、利用者提供の**完全一致する空欄PDF**への基本情報（給与支払者名、申告者フリガナ・氏名・住所）の自動配置を試験実装しています。
- 自動配置は空欄PDFのSHA-256・対象年度・XML種類の一致を必須とします。ファイル名だけの一致では動作しません。
- **控除額、扶養親族の欄、住宅ローン控除の計算・転記にはまだ対応していません。** 印字内容と位置を必ず確認し、提出用として無検証で使わないでください。
- 公式XML定義の参照: https://www.nta.go.jp/users/gensen/oshirase/pdf/03.pdf
- 実際に提出する個人情報を含むXML/PDFはGitHubに置かないでください。

## v0.8 国税庁の入力用PDFへの対応

次のPDFは実際にAcroFormの入力フィールドを持っています。
- 2027bun_01_input.pdf：193ウィジェット（扶養控除等申告書・令和9年）
- 2026bun_06_input.pdf：83ウィジェット（基礎・配偶者等控除・令和8年）
- 2026bun_04_input.pdf：143ウィジェット（保険料控除・令和8年）

入力用PDFは利用者が初回に端末で選択し、ブラウザ内に保存する方式です。公式ダウンロード先へのリンクをアプリ内に表示しています。ソースPDFは本リポジトリに再配布していません。

**現時点の実装は、フォーム欄の矩形情報を利用した文字画像の配置です。PDFのAcroForm値そのものを更新する処理ではありません。** XMLからの基本情報（申告者・勤務先等）のみ初期対応し、控除額、保険契約情報、扶養親族情報、チェックボックスのすべては対応していません。電子申告向けデータとしての利用は想定していません。実際の記入内容は必ず再表示・印刷して確認してください。

フォームの検出はPDF.jsのアノテーション情報、PDF書き出しはpdf-libを使用しています。CDN依存があるため完全なオフライン処理は未実装です。

## v0.9：入力フォーム名による転記設定

- 国税庁の入力用PDFを選択し、XMLの項目を選んでPDFフォーム欄内をタップすると、PDFフォーム名（Text、fill_等）とXML項目の対応を登録します。
- 対応は年度・書類種別・PDF SHA-256に紐づけて端末内に保持し、同じXML構造で復元できます。
- 英数字などWinAnsi/Helveticaで表示可能な文字に限り、pdf-lib の AcroForm テキストフィールドへ直接入力します。
- **日本語は現時点でフォーム値へ直接入力せず、文字画像をPDFページに重ねます。** 日本語のフォーム直接入力は日本語対応フォントの埋め込み・表示更新の検証後に対応します。
- 対応付けを一度登録する必要があります。すべての申告欄を自動判定するものではありません。控除額計算、チェックボックス、住宅ローン控除は未対応です。
- データの氏名、住所、金額、マイナンバーを公開リポジトリへ入れないでください。

## v1.2 暗号化PDFの印刷用フォールバック

- 国税庁の3種類の入力用PDFは暗号化フラグ付きで、空のパスワードで閲覧できますがpdf-libの通常読込は失敗します。
- 暗号化エラーの場合のみ、PDF.jsで各ページを描画して新しいPDFを生成します。印刷専用となり、フォーム編集やテキスト選択はできません。
- 端末メモリを多く使用する可能性があり、iPhone実機では未検証です。PDFの全ページ、文字位置、読みやすさを必ず確認してください。
- 暗号化の無視設定を使用せず、原本は変更しません。

## v1.3: 元PDFの見出し・説明文欠落を防止

- v1.2のPDF.js画像化フォールバックは、文字や項目名が欠落する実例を確認したため**撤去**しました。
- GitHub Actionsの `prepare-templates.yml` で国税庁の公開入力用PDFを取得し、PyMuPDFで暗号化のない閲覧・編集可能な空欄PDFへ正規化します。処理中は元文書と変換後のテキスト量を照合し、減少が大きい場合は保存を中止します。正常なものだけ `templates/` に登録します。
- アプリは既知の国税庁公式PDFを読み込んだ際に、対応する正規化済み空欄PDFを取得して転記に使用します。利用者のXMLや個人情報はリポジトリへアップロードしません。
- 正規化テンプレートが見つからない場合、PDFの元の文字を保護するため出力を停止します。画像化して文字が消える変換には戻しません。
- 各PDFへの転記項目の対応には未完成部分があり、iPhoneでの出力結果は改めて検証が必要です。
